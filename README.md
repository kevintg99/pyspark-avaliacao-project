# Projeto de Avaliação Técnica - PySpark

Este projeto foi desenvolvido como parte de uma avaliação técnica para a vaga de Engenheiro de Dados Jr. Utilizei PySpark para resolver problemas de análise de dados a partir de arquivos CSV e JSON.

## 🔧 Ferramentas Utilizadas

- Python
- PySpark
- Google Colab
- Pandas
- Jupyter Notebook

## 📁 Estrutura dos Dados

- `sales.csv`: informações de vendas
- `users.csv`: dados dos usuários
- `products.json`: catálogo de produtos

## ✅ Tarefas Realizadas

1. Criação dos datasets simulados
2. Cálculo do valor final das compras
3. Total gasto por cliente
4. Top 5 clientes com maior gasto
5. Top 5 produtos mais vendidos no ultimo mes
6. Média e desvio padrão de faturamento por cliente
7. Classificação dos clientes (Silver, Gold, Platinum)
8. Top 3 produtos mais consumidos por categoria de cliente
9. Salvamento de resultado em formato Parquet
